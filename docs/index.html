Avalduse kirjeldus

          
Töötaja saadab selle vormiga raamatupidamisele vabas vormis avalduse, kui Web Desktopi litsentsi enam ei ole ja avaldust ei saa sealt saata.

          
Nimi ja e-post tulevad identiteedist. Vormil ei saa neid käsitsi kirjutada.

          
Avalduse liikide nimekirja peab raamatupidamine. Siin on esialgne loetelu, sealhulgas „Muu“.

          
See GitHub Pagesi koopia ei saada e-kirja. Esitamine koostab kirja ainult selles brauseris. Raamatupidamine seda ei saa.
